# Revisão das diretrizes de interface — 13/10/2026

Fonte consultada antes da revisão: https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md

Aplicação nesta PWA: botões de ícone com rótulo acessível; formulários com labels e autocomplete adequados; ações por elementos semânticos; estados online/offline/loading/error; foco visível e fechamento de gaveta por teclado; áreas seguras mobile; evitar barras e overflow horizontal; alvos de toque de pelo menos 44 px; texto de metadados legível; `prefers-reduced-motion`; links de navegação reais e URLs externas validadas; sem persistência de conteúdo/progresso no service worker.

O código deve continuar seguindo o design monocromático registrado em `DESIGN.md`; a lista externa informa critérios mecânicos, não substitui a preferência visual do usuário.
